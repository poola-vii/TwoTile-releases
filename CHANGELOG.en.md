# Changelog

Dates are in Japan time (JST). The Store version and the portable version use the same version numbers.

This English changelog starts with 1.0.9, the first released version shown in English. For earlier versions, see the [Japanese changelog](CHANGELOG.md).

> **About version numbers during the public beta.** Versions 0.x were used during development before release. We moved to 1.x when we released TwoTile in the Microsoft Store, and **1.0.1** was the first released version. We show that TwoTile is a beta on the download pages and in this document, not in the version number.

---

## 1.0.9 — 2026-10-27

### Added

- **TwoTile is now shown in English.** When the Windows display language is Japanese, TwoTile is shown in Japanese as before. For any other language, the menu, Settings, the debug view, and Help are shown in English. The Terms of Use in Help are a reference translation (the Japanese version is the official one).
  - **If your Windows display language is English, TwoTile is shown in English from 1.0.9.** There's no setting to change the language. If you want to use TwoTile in Japanese, let us know through the [support contact](https://poola-vii.github.io/twotile/support.en.html).
- Help gives the address of this changelog under "Official download sources."

### Settings file

- The settings file hasn't changed. You can switch between 1.0.6 and 1.0.9 and keep using the same settings.
